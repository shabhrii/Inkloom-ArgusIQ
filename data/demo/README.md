# Demo fixtures

Seed a small coherent fictional brand: guidelines, approved facts, terminology, disclosures, channel rules and sample drafts. Fixtures should demonstrate both passing and failing checks.

## Phase discipline
Implement `(1)` work first. Do not begin `(2)` until the Phase (1) workflow passes. Add `(2)` features one at a time and rerun the full test/demo suite after each. Implement `(3)` only after the project remains stable.

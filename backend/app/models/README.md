# Database models

SQLAlchemy persistence models for users, documents, policy knowledge, findings, evidence and review decisions. Use stable IDs, timestamps, foreign keys and explicit status enums. Add migrations for schema changes.

## Phase discipline
Implement `(1)` work first. Do not begin `(2)` until the Phase (1) workflow passes. Add `(2)` features one at a time and rerun the full test/demo suite after each. Implement `(3)` only after the project remains stable.

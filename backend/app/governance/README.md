# Review governance

Phase (1) requires human review, comments/decisions, approvals and revision history. Persist each decision and preserve the original draft. Reviewer decisions can feed reports but must not automatically change approved rules. Risk-adaptive routing and advanced provenance are Phase (2); active learning is Phase (3).

## Implementation sequence
Complete Phase (1) first. Phase (2) must be introduced one feature at a time with full regression tests after each feature. Phase (3) is optional.

# Document processing

Validate and parse supported file types. Extract text and metadata; OCR/image-region extraction is used where supported. Preserve locations for findings. Fail safely when extraction is unreliable.

## Phase discipline
Implement `(1)` work first. Do not begin `(2)` until the Phase (1) workflow passes. Add `(2)` features one at a time and rerun the full test/demo suite after each. Implement `(3)` only after the project remains stable.

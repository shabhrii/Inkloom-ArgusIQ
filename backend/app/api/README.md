# API

Expose versioned endpoints. Routers validate and delegate to services. Enforce authentication, role and organization scope on every protected operation. Do not expose incomplete functionality as operational.

## Phase discipline
Implement `(1)` work first. Do not begin `(2)` until the Phase (1) workflow passes. Add `(2)` features one at a time and rerun the full test/demo suite after each. Implement `(3)` only after the project remains stable.

# Backend scripts

Explicit, repeatable development utilities for database initialization, demo seeding, admin creation and evaluation. Scripts must not embed credentials or destructive production defaults.

## Phase discipline
Implement `(1)` work first. Do not begin `(2)` until the Phase (1) workflow passes. Add `(2)` features one at a time and rerun the full test/demo suite after each. Implement `(3)` only after the project remains stable.

# Pages

Pages compose components and call service hooks. Each page must have loading/error/empty states and enforce route-level access for usability; backend authorization remains mandatory. Implement core pages first.

## Phase discipline
Implement `(1)` work first. Do not begin `(2)` until the Phase (1) workflow passes. Add `(2)` features one at a time and rerun the full test/demo suite after each. Implement `(3)` only after the project remains stable.

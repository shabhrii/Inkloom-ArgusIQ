# Frontend types

Define interfaces/enums that match backend schemas: document state, finding category/severity/status, evidence reference, reviewer action and user role. Update these when API contracts change.

## Phase discipline
Implement `(1)` work first. Do not begin `(2)` until the Phase (1) workflow passes. Add `(2)` features one at a time and rerun the full test/demo suite after each. Implement `(3)` only after the project remains stable.

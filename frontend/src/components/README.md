# UI components

Build reusable components by feature area. Upload components handle user interaction; guidelines components manage rule entry; verification components display typed findings/evidence/corrections; review components record user decisions; analytics components summarize persisted data. Avoid duplicating business logic inside components.

## Phase discipline
Implement `(1)` work first. Do not begin `(2)` until the Phase (1) workflow passes. Add `(2)` features one at a time and rerun the full test/demo suite after each. Implement `(3)` only after the project remains stable.

# Frontend

React + TypeScript + Vite UI. Keep components presentational where practical, put API calls in services, share types in types/, and handle loading, empty, error and permission states. The frontend is not an authorization boundary. Phase (1) pages and components first; Phase (2) additions individually; Phase (3) last.

## Phase discipline
Implement `(1)` work first. Do not begin `(2)` until the Phase (1) workflow passes. Add `(2)` features one at a time and rerun the full test/demo suite after each. Implement `(3)` only after the project remains stable.

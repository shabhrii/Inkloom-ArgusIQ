# Known limitations

Maintain this document as the implementation evolves.

For every limitation, record:
- Feature affected.
- Current behavior.
- Why it is limited.
- Risk to users.
- Workaround or human-review requirement.
- Planned next step.

Expected limitations to evaluate include imperfect PDF/DOCX extraction, OCR errors, stale or conflicting approved sources, false positives/negatives, AI-provider downtime, unsupported file types, limited visual checks and incomplete privacy controls. Keep only limitations that apply to the current build and add discovered ones.

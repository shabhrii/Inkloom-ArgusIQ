# User guide

## Typical workflow
1. Sign in using an authorised account.
2. Add or review approved brand rules, facts, terminology and disclosures.
3. Upload a supported draft.
4. Start verification and wait for extraction/checking to complete.
5. Review findings, source evidence and suggested corrections.
6. Accept, reject, edit or escalate each finding as permitted by the user's role.
7. Submit the content through the required approval workflow.
8. Reopen the document's revision history to inspect recorded decisions.

A clean result means no issues were detected by the checks that actually ran; it is not a guarantee that the content is universally correct or fully on-brand.

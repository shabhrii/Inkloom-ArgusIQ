# Judge demonstration guide

## Preparation
- Use fictional demo brand data only.
- Seed one approved brand guideline, a handful of approved facts, terminology and a required disclosure.
- Prepare one compliant draft and one deliberately flawed draft.
- Prepare an approved logo asset and a modified test image only if visual checking is implemented.
- Verify the demo environment and test accounts before presenting.

## Suggested demo
1. Show the approved policy/facts.
2. Upload the flawed draft.
3. Run verification.
4. Open one finding and show the exact source/rule and why it was flagged.
5. Preview the proposed correction; show that the source is not silently overwritten.
6. Record a reviewer decision.
7. Show the persisted review history.
8. If implemented, demonstrate a visual discrepancy and a recurring-issue summary.

Clearly distinguish working features from roadmap items. Do not fake test results or present mock screens as live functionality.
